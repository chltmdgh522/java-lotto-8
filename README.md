# 🎰 로또 - 구현 기능 목록

## 1️⃣ 입력 처리 기능
- [ ] 사용자로부터 **로또 구입 금액**을 1000원 단위로 입력받고, **당첨 번호(6개)** 는 쉼표(`,`)를 기준으로, **보너스 번호(1개)** 를 입력받는다.
- [ ] 구입 금액이 1000원으로 나누어 떨어지지 않을 경우 **예외를 발생시킨다.**
- [ ] 당첨 번호가 6개가 아니거나, 쉼표 구분이 잘못되었거나, 숫자가 범위를 벗어날 경우 **예외를 발생시킨다.**
- [ ] 또한 당첨 번호가 **중복될 경우 예외를 발생시킨다.**
- [ ] 보너스 번호 또한 범위를 벗어나거나 잘못 입력했을 경우 **예외를 발생시킨다.**
- [ ] 입력 예외가 발생할 경우 프로그램을 종료하지 않고, `[ERROR]`로 시작하는 에러 메시지를 출력한 후 **그 부분부터 다시 입력받는다.**

---

## 2️⃣ 로또 객체 생성 및 상태 관리
- [ ] **Enum**을 활용하여 **당첨 번호**와 **추천 번호**를 구분하고, `Map` 에 저장한다.
- [ ] 당첨 번호 6개를 `Map<Long, Lotto>` 형태로 저장한다.
- [ ] 이후 사용자가 입력한 금액에 맞게 **순서대로 추첨 번호**도 `Map<Long, Lotto>` 형태로 저장한다.
- [ ] 이때 `Randoms.pickUniqueNumbersInRange(1, 45, 6)` 를 활용하여 추첨 번호를 무작위로 생성한 뒤 **오름차순으로 저장**한다.
- [ ] 보너스 번호는 당첨 번호일 때는 입력하고, 추천 번호일 때는 0으로 저장한다.
- [ ] 즉, 최종 컬럼은 **로또 번호들**, **번호 종류**, **보너스 번호**, **당첨 통계 외래키**, **수익률 외래키**이다.

---

## 3️⃣ 당첨 통계 객체 생성 및 상태 관리
- [ ] 로또 객체와 외래키를 연결한다. (연관관계의 주인은 로또 객체, 다대일 관계)
- [ ] **Enum**으로 3개, 4개, 5개, 5+보너스, 6개 일치 상태를 정의한다.
- [ ] 각 상태에 맞는 **당첨 금액**을 설정한다.

---

## 4️⃣ 수익률 객체 생성 및 상태 관리
- [ ] 로또 객체와 외래키를 연결한다. (연관관계의 주인은 로또 객체, 다대일 관계)
- [ ] 초기에는 객체만 생성하고, 이후 **수익률 계산 시 업데이트**를 수행한다.
- [ ] 컬럼은 **수익률 1개**이다.

---

## 5️⃣ 실행 결과 출력
- [ ] 발행된 **로또 수량 및 각 로또 번호**를 출력한다.
    - 예시:
      ```
      8개를 구매했습니다.
      [8, 21, 23, 41, 42, 43]
      [3, 5, 11, 16, 32, 38]
      [7, 11, 16, 35, 36, 44]
      ...
      ```
- [ ] 당첨 결과를 아래와 같은 형식으로 출력한다.
    - 예시:
      ```
      당첨 통계
      3개 일치 (5,000원) - 1개
      4개 일치 (50,000원) - 0개
      5개 일치 (1,500,000원) - 0개
      5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
      6개 일치 (2,000,000,000원) - 0개
      총 수익률은 62.5%입니다.
      ```

---

## 6️⃣ 코드 규칙 및 품질
- [ ] **들여쓰기(depth)** 는 최대 2단계까지만 허용한다.
- [ ] **삼항 연산자**를 사용하지 않는다.
- [ ] 메서드는 **한 가지 역할만 수행**하도록 최대한 작게 분리한다.
- [ ] **Java Code Convention**을 준수한다.
- [ ] `else` 예약어나 `switch/case` 문을 사용하지 않는다.
- [ ] **단위 테스트**를 작성한다.
- [ ] **Java Enum**을 적용하여 프로그램을 구현한다.

---

## 7️⃣ 테스트 코드 (JUnit5 + AssertJ)
- [ ] 구입 금액이 1000원 단위가 아닐 때 예외 발생 테스트
- [ ] 로또 번호가 6개가 아닐 때 예외 발생 테스트
- [ ] 로또 번호가 중복되었거나 범위를 벗어났을 때 예외 발생 테스트
- [ ] 발행된 로또 개수가 구입 금액 / 1000 과 일치하는지 테스트
- [ ] 당첨 번호와의 일치 개수에 따라 올바른 등수(1~5등)가 계산되는지 테스트
- [ ] 수익률 계산이 올바른지 테스트

# 🧾 Commit Convention (AngularJS Style)

| Type | Description |
|------|--------------|
| **feat** | 새로운 기능 추가 |
| **fix** | 버그 수정 |
| **docs** | 문서 수정 (README 등) |
| **style** | 코드 포맷 변경 (세미콜론, 공백 등 — 기능 영향 없음) |
| **refactor** | 코드 리팩토링 (기능 변경 없이 구조 개선) |
| **test** | 테스트 코드 추가 또는 수정 |
| **chore** | 빌드, 설정, 기타 유지보수 작업 |
